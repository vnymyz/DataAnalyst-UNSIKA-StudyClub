while: Kejar Target Penjualan

        

          Loop terus berjalan selama kondisinya masih benar.
          Coba juga tombol kedua — versi yang lupa update counter, biar

target = 500000
total_terkumpul = 0
hari = 0

while total_terkumpul < target:
    total_terkumpul += 100000

Teori 11

        
break vs continue

        

          break menghentikan seluruh loop.
          continue cuma melewati satu item, loop tetap lanjut.
          Jalankan keduanya dan bandingkan mana yang berhenti duluan.
        


        

          

            

              break — berhenti saat stok habis
            

            
stok = [5, 3, 0, 8]
for jumlah in stok:
    if jumlah == 0:
        break
    print(f"Sisa stok: {jumlah}")

            
            

          

          

            

              continue — lewati data kosong
            

            
penjualan = [120000, 0, 95000, 0, 200000]
for nilai in penjualan:
    if nilai == 0:
        continue
    print(f"Transaksi: {nilai}")

Function: Masukkan Bahan, Keluar Hasil

        

          Atur harga dan jumlah, lalu jalankan
          hitung_total(harga, jumlah). Function memproses seperti

Default parameter

            
def hitung_diskon(total, persen=0.10):
    return total * persen

            

              Kalau persen tidak diisi saat dipanggil, otomatis
              pakai 0.10. Contoh:
              hitung_diskon(200000) →
              20000.0.
            

          

          

            
print() vs return

            

              print() cuma menampilkan ke layar, hasilnya tidak
              bisa disimpan (jadi None kalau ditampung variabel).
              return mengirim nilainya keluar, bisa dipakai lagi —
              persis seperti kotak "return" di diagram mesin di atas.

Teori 15

        
Class = Cetakan, Object = Hasilnya

        

          Klik salah satu produk untuk melihat .info()-nya. Dua
          object ini dibuat dari cetakan (class) yang sama, tapi datanya
          masing-masing berbeda.
        


        
class Produk:
    def __init__(self, nama, harga):
        self.nama = nama
        self.harga = harga

    def info(self):
        return f"{self.nama} - Rp {self.harga}"
