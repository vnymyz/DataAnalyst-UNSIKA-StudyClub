# Latihan 2 — Logika dan Function

1. Buat program yang memberi label `"Lulus"` bila nilai minimal 75, selain itu `"Perlu belajar lagi"`.
2. Cetak angka 1–10 menggunakan `for`; tampilkan hanya angka genap.
3. Buat `while` yang menghitung mundur dari 5 sampai 1.
4. Buat function `hitung_total(harga, jumlah)` yang mengembalikan total pembayaran.
5. Buat function kategori penjualan: `< 100000` rendah, `100000–499999` sedang, sisanya tinggi.
