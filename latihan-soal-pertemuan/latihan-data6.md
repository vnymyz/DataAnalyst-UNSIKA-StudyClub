# Latihan 6 — Streamlit dan GitHub

1. Buat struktur folder proyek sesuai modul sesi 6.
2. Buat `app.py` yang memuat CSV dan menampilkan judul serta lima baris pertama data.
3. Tambahkan satu `st.metric` untuk total penjualan.
4. Tambahkan filter kategori memakai `st.multiselect`.
5. Buat repository GitHub, lakukan satu commit dengan pesan yang bermakna, lalu tulis README minimal.
