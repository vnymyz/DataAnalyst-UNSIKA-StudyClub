# Latihan 1 — Python Dasar

1. Buat variabel `nama`, `jurusan`, dan `semester`, lalu tampilkan satu kalimat dengan f-string.
2. Buat list berisi lima kategori produk. Cetak kategori ketiga.
3. Buat dictionary `produk` dengan key `nama`, `harga`, dan `stok`. Tampilkan harga produknya.
4. Ubah nilai stok menjadi stok lama dikurangi 2, lalu tampilkan dictionary terbaru.
5. Jelaskan kapan kamu memakai list dan kapan memakai dictionary.
