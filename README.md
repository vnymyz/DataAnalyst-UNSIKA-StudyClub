# Data Analyst UNSIKA

Materi 6 pertemuan untuk mahasiswa pemula, durasi **19.30–21.00 WIB** setiap sesi.

## Tujuan akhir

Peserta mampu mengolah data CSV dengan Python, menghasilkan visualisasi dan insight, lalu memahami cara membuat dashboard Streamlit sederhana serta mendokumentasikan proyek di GitHub.

## Struktur

- `materi-pertemuan/` — modul dan rundown kelas.
- `latihan-soal-pertemuan/` — latihan serta kuis sesi 1–5.
- `kunci-jawaban-pertemuan/` — kunci latihan dan kuis.
- `panduan-setup.md` — persiapan tools.
- `panduan-proyek-akhir.md` — brief proyek kelompok setelah sesi 6.

> Mulai dari `materi-pertemuan/pertemuan-01.md`. Peserta mengerjakan latihan sebelum membuka kunci jawaban.
