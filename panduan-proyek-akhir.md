# Panduan Proyek Akhir — Dashboard Data

Proyek dikerjakan **setelah sesi 6** dalam kelompok berisi **3–4 orang**. Detail tenggat dan ada/tidaknya presentasi akan diumumkan kemudian.

## Tujuan

Buat dashboard Streamlit yang menjawab pertanyaan analisis nyata dari sebuah dataset CSV. Dashboard tidak dinilai dari banyaknya grafik, melainkan dari kejelasan pertanyaan, kualitas pengolahan data, insight, dan cara menyampaikannya.

## Ketentuan minimum

1. Pilih dataset publik yang legal digunakan, misalnya dari Kaggle. Cantumkan sumbernya.
2. Lakukan data understanding dan cleaning dasar.
3. Buat minimal 3 visualisasi yang relevan dan 3 insight/rekomendasi.
4. Buat dashboard dengan judul, filter/interaksi yang berguna, grafik, dan bagian kesimpulan.
5. Simpan kode dalam repository GitHub; setiap anggota melakukan minimal satu kontribusi yang terdokumentasi.
6. Sediakan `README.md`: anggota kelompok, sumber data, pertanyaan analisis, cara menjalankan aplikasi, dan ringkasan insight.

## Ide cadangan

- Analisis penjualan e-commerce: tren penjualan, kategori produk, pelanggan, dan wilayah.
- Analisis performa mahasiswa atau pendidikan.
- Analisis kualitas udara/lingkungan.
- Analisis film, musik, atau game.

## Pengumpulan dan presentasi

Pengumpulan dapat menggunakan tautan repository GitHub atau Google Drive sesuai arahan penyelenggara. Bila ada presentasi, setiap kelompok menyiapkan demo dashboard dan penjelasan singkat: masalah, data, tiga insight, serta rekomendasi.

## Rubrik awal (100 poin)

| Aspek | Poin |
|---|---:|
| Rumusan masalah dan pemahaman data | 20 |
| Cleaning serta analisis yang tepat | 25 |
| Visualisasi dan insight | 25 |
| Dashboard Streamlit dan pengalaman pengguna | 20 |
| Dokumentasi, GitHub, dan kontribusi kelompok | 10 |
